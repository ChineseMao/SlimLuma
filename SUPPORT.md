# Support / 使用支持

SlimLuma is a community-maintained open-source project. Support is provided
through GitHub and may be written in any of the 20 languages listed in the
[README](README.md).

SlimLuma 是由社区维护的开源项目。请通过 GitHub 获取支持，并可使用
[README](README.zh-CN.md) 中列出的任意一种受支持语言。

## Before opening an issue / 提交 Issue 前

1. Confirm that you are using the
   [latest release](https://github.com/ChineseMao/SlimLuma/releases/latest).
2. Open **Engines & Settings** and check the detected engine and version.
3. Retry with a synthetic or non-private file when possible.
4. Search existing issues for the same format, engine, or error.

1. 确认正在使用[最新版本](https://github.com/ChineseMao/SlimLuma/releases/latest)。
2. 打开“引擎与设置”，确认实际检测到的引擎及版本。
3. 尽量使用合成文件或不含隐私的文件复现。
4. 搜索已有 Issue 中是否存在相同格式、引擎或错误。

## Where to ask / 在哪里反馈

- Use the
  [bug report form](https://github.com/ChineseMao/SlimLuma/issues/new?template=bug-report.yml)
  for reproducible failures.
- Use the
  [feature request form](https://github.com/ChineseMao/SlimLuma/issues/new?template=feature-request.yml)
  for a scoped workflow improvement.
- Follow the [Security Policy](SECURITY.md) for vulnerabilities or possible
  data exposure.

- 可复现故障请使用
  [错误报告表单](https://github.com/ChineseMao/SlimLuma/issues/new?template=bug-report.yml)。
- 明确的工作流改进请使用
  [功能建议表单](https://github.com/ChineseMao/SlimLuma/issues/new?template=feature-request.yml)。
- 漏洞或潜在数据泄露请遵循[安全策略](SECURITY.md)。

## Include / 建议提供

- SlimLuma version, macOS version, Mac architecture, and selected app language;
- media type and a non-private sample or minimal reproduction;
- selected preset and relevant custom settings;
- detected engine names and versions;
- redacted logs, expected behavior, and actual behavior.

- SlimLuma 版本、macOS 版本、Mac 架构及应用语言；
- 媒体类型，以及不含隐私的样本或最小复现；
- 预设与相关自定义设置；
- 检测到的引擎名称和版本；
- 脱敏日志、预期结果与实际结果。

Never publish passwords, encrypted-document contents, private media, signing
credentials, API keys, or unredacted personal paths.

请勿公开密码、加密文档内容、私密媒体、签名凭据、API Key 或未脱敏的个人路径。
