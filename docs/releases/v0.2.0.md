# SlimLuma 0.2.0

Local, non-destructive image, animated image, video, and PDF compression for
macOS. 本地、不覆盖原件的 macOS 图片、动画、视频与 PDF 压缩工具。

## Highlights / 重点

- Image target size and H.264 / HEVC two-pass target size.
- Per-file queue settings, real progress, ETA, pause and resume.
- Encrypted PDF support and PDF structure / encryption validation.
- Homebrew engine detection, guided installation and automatic continuation.
- Finder, Shortcuts, watched folders, clipboard and standalone CLI.
- 20 product locales, including Arabic, Urdu and Shahmukhi RTL.
- Universal `arm64` + `x86_64`, Developer ID, Apple notarization and SHA-256.

- 图片目标大小与 H.264 / HEVC 两遍目标大小。
- 逐文件设置、真实进度、预计剩余时间、暂停与继续。
- 加密 PDF、PDF 结构与加密状态守门。
- Homebrew 引擎检测、安装引导与就绪后自动续装。
- Finder、快捷指令、监控目录、剪贴板和独立 CLI。
- 20 个产品 locale，包含阿拉伯语、乌尔都语和 Shahmukhi RTL。
- Universal `arm64` + `x86_64`、Developer ID、Apple 公证和 SHA-256。

## Verify / 验证

Download `SHA256SUMS` with the release files, then run:

```bash
shasum -a 256 -c SHA256SUMS
```
